4. Compilación

Comando utilizado para generar dist/output.css:

npm install
npx tailwindcss -i ./src/input.css -o ./dist/output.css

# Recompilar solo al guardar:
npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch

El CSS generado contiene únicamente las clases usadas en index.html: los colores marca, acento y tinta existen porque fueron declarados en la configuración.
